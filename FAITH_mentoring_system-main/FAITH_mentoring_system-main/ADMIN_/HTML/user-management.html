    How it works
    Adding new users ▼
    1. Download the blank template below and open it in Excel.
    2. Delete the 3 example rows (rows starting with *** DELETE THIS ROW).
    3. Fill one user per row. Required: First Name, Last Name, Email, Password, Role.
    4. For Mentors — fill School and the exact Department name from the reference. Leave Course blank. For a mentor in a School Department (e.g. SAS, ASC, FCS, FSHS), leave School blank and put that department's name as the Department.
    5. For Mentees — fill School and the exact Course code from the reference (leave Department blank) — use a course listed under the selected school; unrecognized course codes are rejected for new mentees. Put the mentor's email in the last column to assign one.
    6. For Admins/Head — basic info only. Leave School, Department, Course, and Mentor Email blank.
    Updating existing users ▼
    1. Download Current Users below instead — each row is already filled in with everyone's real, current info.
    2. A row updates the person it matches by Email — don't change that column, or it'll be treated as a different person.
    3. Edit only the cells you want to change. Leave the rest exactly as downloaded — First Name, Last Name, Email, and Role must remain filled in. Blank optional fields keep their existing values.
    4. Password stays blank and is never touched by import, even if you type something in it. To reset someone's password, use the ✏️ Edit action on that person instead.
    5. Put a different email in the last column to reassign a mentee's mentor.
    Then, either way
    1. Save as CSV UTF-8 in Excel (File → Save As → CSV UTF-8).
    2. Click Step 2 and select your file.
    Step 1 — Download a starting point
    Step 2 — Upload your edited file
    Valid Values
    Role:  Admin  ·  Head  ·  Mentor  ·  Mentee
    Gender:  Male  ·  Female
    School:  SOT  ·  SOH  ·  SOM  ·  blank for School Department mentors
    Departments (Mentor — click to expand)
    Courses (Mentee — click to expand. A Department, e.g. CCIT, groups several of these — use the Course code here, not the Department name.)
